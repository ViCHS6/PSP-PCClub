# PSP-PCClub

**Симулятор владельца компьютерного клуба начала 2000-х для Sony PSP.** Вид от первого лица, low-poly 3D и рабочий стол администратора прямо в игре.

**1 сентября 2001 года.** В подвале жилого дома открывается компьютерный клуб на шесть мест. На стойке касса, вдоль стен — бежевые системники и ЭЛТ-мониторы. У тебя очередь, пятый компьютер завис, а кто-то просит продлить ещё на час. До закрытия нужно успеть со всем разобраться.

## Как устроена игра

- **Обслуживай посетителей.** Назначай места, выбирай тариф и продлевай сеансы. У клиентов разные вкусы, бюджеты и запас терпения.
- **Следи за компьютерами.** Ходи по залу, перезагружай зависшие ПК, чисти системники от пыли и устанавливай игры.
- **Управляй клубом из-за стойки.** Когда садишься за компьютер администратора, камера приближается к монитору. Касса, Сеть, Магазин, Почта, Бухгалтерия и Рекорды открываются с рабочего стола.
- **Развивай клуб.** Выручка идёт на игры, обслуживание и новое железо. Спрос меняется вместе с расписанием посетителей и игровым календарём.

## Состояние проекта

В сборке для разработки уже есть интерактивный зал на шесть мест, симуляция очереди и экономики, ОС администратора, «Змейка», мини-игры обслуживания и сохранения. Ближайшая веха — собрать полный игровой день, довести поведение 3D-посетителей и проверить самую нагруженную сцену на консоли. После этого в планах расширение зала, ночной тариф и турниры для бесконечного режима. [Дорожная карта](docs/TASKS.md)

Ранний билд с базовыми ассетами показал **60 FPS на реальной PSP Go**. Цель для релиза — **стабильные 30 FPS в самой нагруженной сцене**. 60 FPS остаются возможным бонусом. Игра рассчитана на ограничения PSP-1000, включая бюджет до 20 МиБ оперативной и 2 МиБ видеопамяти.

## Сборка и запуск

Команды выполняются из корня репозитория в Ubuntu 24.04 / WSL2. Понадобятся Git LFS, CMake, Ninja, Python 3 с Pillow и PSPDEV для сборки под консоль. Установка зависимостей описана в [инструкции по настройке](docs/SETUP.md).

### Sony PSP и PPSSPP

```bash
git lfs pull
psp-cmake -S . -B build/psp -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build/psp
```

В PPSSPP открой `build/psp/EBOOT.PBP`. Для запуска на PSP с поддержкой homebrew скопируй `EBOOT.PBP`, `data.pak`, `scene_club.json` и папку `assets/` из `build/psp/` в `PSP/GAME/PCCLUB/` на накопителе консоли.

В зале крестовина отвечает за ходьбу, стик — за обзор, **×** — за взаимодействие. **SELECT** открывает отладочный оверлей с FPS и расходом памяти. [Управление](docs/controls.md)

### Сборка для ПК

Сборка на SDL2/OpenGL предназначена для разработки, тестов и проверки игрового баланса.

```bash
cmake -S . -B build/pc -G Ninja
cmake --build build/pc
ctest --test-dir build/pc --output-on-failure
./build/pc/pcclub
```

## Под капотом

Ядро симуляции написано на **C++17** и работает независимо от платформы. На PSP графика использует **GU/GUM**, а для ПК есть рендерер на **SDL2/OpenGL**. Python-скрипты проверяют игровые данные, собирают `data.pak` и конвертируют модели и текстуры. Утилита `balance-runner` прогоняет экономику клуба на десятках игровых дней.
