# Управление в мире (T010)

Схема — GDD §9.1. Реализация: `src/game/player.*` (камера, ходьба, коллизия),
`src/game/interact.*` (липкий прицел, подсветка, подсказки, ×/□). Числа «ощущений» —
`game::controls` в `src/game/player.h` и конус прицела в `src/game/interact.cpp`.

PSP-1000 и PSP Go: кнопки одинаковые, стик один — схема общая, отличий в коде нет.

## Схема

| Кнопка PSP | PC (клавиатура) | Действие | Статус |
|---|---|---|---|
| Стик ↑/↓ | W / S | Ходьба вперёд/назад, 1,4 м/с | ✓ |
| Стик ←/→ | A / D | Поворот, до 2,4 рад/с (≈ 137°/с) | ✓ |
| L (удерживать) + стик | Q + WASD | Свободный обзор: поворот и наклон, без ходьбы | ✓ |
| × | K | Взаимодействовать с предметом под прицелом | ✓ |
| □ | J | Контекстное действие предмета (если есть) | ✓ |
| R (удерживать) | E | Быстрая ходьба, 2,6 м/с | ✓ |
| ○ | L | Отмена / назад | — (ОС, T030/T033) |
| △ | I | Блокнот просьб и проблем | — (позже) |
| START | Enter | Пауза / системное меню | — (позже) |
| SELECT | Backspace | Часы: время, скорость | ⚠ пока отладочный оверлей |
| Крестовина ←/→ | ← / → | Шаг вбок, 0,8 м/с (R не ускоряет), работает и с L | ✓ (T015) |
| Крестовина ↑/↓ | ↑ / ↓ | В мире не используется — резерв | см. ниже |

## Как это работает

- **Отклик стика** — квадратичный (`kStickCurve = 2`): лёгкое отклонение даёт точный
  доворот, до упора — полную скорость.
- **Наклон** взгляда — от −60° до +50°. Без L наклон стиком не меняется; при ходьбе без
  цели он плавно возвращается к −8°, иначе на одном стике его не поправить.
- **Липкий прицел.** Цель — предмет, AABB которого пересекает луч взгляда (ближайший), иначе
  предмет с наименьшим углом до своей точки прицела в конусе 12°. Захваченная цель держится
  до 17° (гистерезис, без мигания). Предмет дальше `max_distance` (по умолчанию 2 м) не
  выбирается. Пока цель есть, поворот замедляется (×0,57), а взгляд подтягивается к точке
  прицела (4,75/с) — если стик повёрнут меньше чем на 0,6. Сильный поворот срывает прицел.
- **Подсветка** — жёлтые уголки вокруг проекции AABB на экран (`draw_model` не умеет
  подкрашивать модель). В центре экрана — точка прицела, жёлтая при наличии цели.
- **Подсказка** внизу экрана: «× Перезагрузить ПК 4», вторая строка — □-действие.
  Тексты — ключи `world.*` из `data/strings_ru.json`.
- **Коллизия**: игрок — цилиндр радиусом 0,25 м, выталкивается из AABB мебели и стен по
  плоскости XZ со скольжением. Препятствия ниже 0,2 м и выше 1,75 м не мешают.

## Демо (PC и PSP)

Два рабочих места из заглушек T013. На системнике: × — включить/выключить ПК, □ — сдуть
пыль. На мониторе включённого ПК: × — перезагрузить (экран гаснет на 1,5 с).

build/pc/pcclub --frames 90 --screenshot build/pc/shot_t010.bmp

## Решения после проверки на Go (T015)

1. **Стрейф** — нужен («слегка ходить вбок»): крестовина ←/→, 0,8 м/с — медленнее шага,
   R не ускоряет. Правка GDD §9.1 внесена.
2. **Крестовина ↑/↓** — не занята. Наклон уже есть на L + стик (на Go признан удобным), а
   дублировать его не нужно; ↑/↓ оставлены в резерве под быстрые действия мира (например,
   листание блокнота △ без входа в ОС).
3. **L для обзора** — удобно, без изменений.
4. **Липкость прицела** — «в самый раз, может на 5 % меньше»: притяжение 5,0 → 4,75 1/с,
   трение 0,55 → 0,57 (замедление поворота 45 % → 43 %). Конус 12°/17° не менялся —
   он решает, *что* выбирается, а не насколько сильно тянет.

## Открытые вопросы

1. **SELECT** сейчас переключает отладочный оверлей (T001), а по GDD это часы. Когда появятся
   часы — оверлей перенести на комбинацию (например, SELECT + L).
2. **Глифы кнопок.** В отладочном шрифте нет ○ △ □ — в подсказке □ пока выглядит как «[]».
   Нужны в шрифте UI (T030).
3. **Ряд из 6 ПК (T014):** не «прилипает» ли прицел к соседнему монитору — проверить на Go.
4. **Перекрытие.** Прицел не проверяет, что предмет закрыт другим (через стену/стойку можно
   навестись). Для зала из T014 это не должно мешать — если помешает, добавить проверку луча
   по коллайдерам.
