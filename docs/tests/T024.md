# T024 — ТЗ на тесты формул (вслепую)

Тесты пишутся **по GDD §7 и `src/core/formulas_api.h`, не по реализации**. Реализация — `src/core/formulas.cpp` (T022); читать её, смотреть ветки `claude/T022*` и любые `src/core/*.cpp` запрещено. Если ожидаемое значение здесь расходится с GDD или с комментарием в `formulas_api.h` — не подгоняй тест, а напиши об этом в отчёте.

Все ожидаемые значения ниже посчитаны вручную; в скобках — расчёт.

## Общие правила

- Файл `tests/core/test_formulas.cpp` (можно разбить на `test_formulas_*.cpp` по разделам). Фреймворк — doctest, как в `tests/core/test_contract.cpp`. `using namespace core::formula;`.
- Сравнение float — только через `doctest::Approx(x).epsilon(1e-4)`; для вероятностей меньше 0,01 — `.epsilon(1e-6)`. Целые (`int32_t`, `int`, `bool`) — точное `==`.
- Один `TEST_CASE` на функцию (или на тесную группу), имя — по-русски с номером раздела: `"§7.4 effective_score: перегрев и вирус"`.
- Литералы — `float` с суффиксом `f`, без `double`.
- Монотонность проверять циклом по сетке значений (шаг указан), сравнивая соседние точки: `CHECK(f(x_{i+1}) >= f(x_i))`.

## Сборка, пока нет T022

`formulas.cpp` в `main` ещё нет, поэтому тесты пока не слинкуются. В `CMakeLists.txt` (только блок «Тесты») сделай так:

- если существует `src/core/formulas.cpp` — тестовые файлы формул добавляются в `pcclub_tests` (как остальные);
- иначе — собираются отдельной OBJECT-библиотекой `pcclub_formula_tests_obj` (только компиляция, с `doctest::doctest` и `pcclub_core`, `-Wall -Wextra`), чтобы проверить хотя бы, что тесты компилируются по контракту.

После слияния T022 тесты включатся сами.
