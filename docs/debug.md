# Программа «Отладка»

Инструмент разработки, не часть игры. Это программа в ОС администратора с админскими командами: сценарии, на которые в обычной игре уходят минуты, проверяются за секунды.

- Включается CMake-опцией `PCCLUB_DEBUG_TOOLS` (по умолчанию **ON** и для PC, и для PSP: тесты идут на Release-сборке с Go). Выключить перед релизом — T063.
- Код: `src/ui/apps/debug*`, `src/core/debug_cmds*`, тесты — `tests/core/test_debug_cmds.cpp`, `tests/ui/test_debug_app.cpp`.
- Открыть: START (или × у стойки) → рабочий стол → значок «Дб».
- Управление: ↑/↓ — команда, ←/→ — выбор (ПК, событие), × — выполнить, ○ — закрыть.

## Команды

| Группа | Команды |
|---|---|
| Деньги | +1 000 ₽, +10 000 ₽ |
| Время | до открытия (9:00), до закрытия (24:00), до утра (8:00); скорость ×1 / ×4 / ×16 — в обход замедления при очереди |
| Клуб | посетитель в очередь; все игры на все ПК |
| ПК | выбранный ПК: сломать, повесить, запылить, починить |
| Сохранение | сохранить (только утром, 8:00–9:00, как в игре), загрузить, стереть слот (с подтверждением) |
| Событие | показать любое событие письмом в Почте, без условий и броска |

Сверху строка состояния: день, время, фаза, деньги, очередь. При неудачной записи или чтении слота показывается код носителя (`0x8011…`) — его и надо прислать, если сохранение на Go не работает.

## Типовые проверки

**Сохранение:** «До закрытия» → игра сама сохраняется при закрытии → «До утра» → «Сохранить» → выйти в XMB, «Сохранённые данные»: слот «Компьютерный клуб» → перезапустить игру: день и деньги те же. «Стереть» — чтобы снова начать новую игру.

**Обслуживание посетителя:** «Все игры на все ПК» → «До открытия» → «Посетитель в очередь» → подойти к стойке, × → Касса уже с посетителем: ←/→ тариф, ↑/↓ место, × — сел. Время обслуживания — в оверлее (SELECT), строка «Стойка».

**Обслуживание ПК:** выбрать ПК → «Повесить» / «Запылить» / «Сломать» → подойти к ПК в зале и устранить мини-игрой (перезагрузка, чистка); сломанный — пока только «Починить» из «Отладки» (замены детали ещё нет).
