# Арт-библия

Правила для всех, кто делает графику: вас, Claude Code через Blender MCP, скриптов Codex. Бюджеты производительности — в [GDD §10.3](../GDD.md#103-бюджеты-стартовые-проверить-замерами-на-go); здесь они повторены там, где нужны при моделировании.

Статус: **Утвержден**. Утверждается задачей A001 — до этого числа и палитра могут меняться.

---

## 1. Стиль

**Одной фразой:** low-poly эпохи PS1/PS2 с запечённым светом и маленькими текстурами с палитрой, в интерьере, который знает каждый, кто ходил в клуб в 2001-м.

- **Форма важнее детали.** Предмет узнаётся по силуэту с 2–3 метров на экране 480×272. Мелочи — текстурой, не геометрией.
- **Свет запечён** в цвета вершин. Динамического освещения нет, кроме, возможно, мигания ламп.
- **Текстуры маленькие и честно пиксельные:** фильтрация допустима, но рисуем так, чтобы и без неё выглядело хорошо.
- **Грязь и износ** — да, в меру: потёртый линолеум, затёртые клавиши, скотч на наушниках. Без разрухи.
- **Тепло:** клуб должен выглядеть местом, куда хочется вернуться, а не подвалом из хоррора.

**Референсы:** собираются в `docs/art_refs/` (задача A001). Направления для поиска: фото компьютерных клубов 1999–2004, интерьеры ЖЭКов и подвалов, бежевые ПК и ЭЛТ-мониторы, игры PS1/PS2 с бытовыми интерьерами.

## 2. Палитра

Общая палитра зала задаёт настроение и экономит CLUT: каждая текстура пропса берёт цвета из этой гаммы.

| Группа | Цвета | Hex (ориентир) |
|---|---|---|
| Стены, низ | Масляная краска «панельный зелёный» | `#5E7A5A`, `#4B6449` |
| Стены, верх и потолок | Побелка, пожелтевшая | `#D9D2BC`, `#BFB79F` |
| Пол | Линолеум «под паркет», коричневый | `#7A5638`, `#5E412A` |
| Мебель | ДСП «орех», кромка | `#8A6440`, `#6B4C30` |
| Техника | Бежевый пластик, пожелтевший | `#D8D0B8`, `#B8AE94`, `#8F8670` |
| Стулья | Ткань тёмно-синяя / чёрный дерматин | `#2F3A55`, `#222222` |
| Свет ламп | Дневной холодный / тёплый у стойки | `#E8F0F0` / `#FFD9A0` |
| Акценты | Экраны и плакаты | `#2050C0` (BSOD), `#30C050`, `#E04030`, `#F0C020` |

Акцентные цвета — только на экранах, плакатах, вывесках и коробках с играми. Всё остальное приглушено.

## 3. Масштаб, оси, точка отсчёта

| Правило | Значение |
|---|---|
| Единицы | 1 единица Blender = **1 метр** |
| Оси | Blender: Z вверх, −Y вперёд. Скрипт выгрузки переводит в оси движка — в Blender ничего не поворачивать |
| Точка отсчёта (origin) | Пропсы — **на полу, по центру основания**. Предметы на столе (монитор, клавиатура) — по центру нижней грани. Двери — на оси петель |
| Трансформации | Перед выгрузкой применены (`Ctrl+A → All Transforms`): масштаб 1, поворот 0 |
| Эталон | В шаблонном файле — фигура человека 1,75 м и стол высотой 0,75 м |

**Ориентиры размеров:** стол 1,2 × 0,7 × 0,75 м; ЭЛТ 17″ ~0,42 × 0,42 × 0,43 м; системник 0,19 × 0,45 × 0,43 м; стул — сиденье на 0,46 м; стойка администратора — 1,05 м высотой.

## 4. Бюджеты

| Ассет | Треугольники | Текстура | Материалы |
|---|---|---|---|
| Рабочее место целиком (стол + монитор + системник + клавиатура + мышь + наушники + стул) | ≤ 450 | 1 атлас 128×128 | ≤ 2 |
| Отдельный мелкий проп (телефон, часы, урна) | ≤ 60 | из общего атласа пропсов | 1 |
| Крупный проп (стойка, полка, холодильник) | ≤ 300 | 128×128 | ≤ 2 |
| Комната (зал на 6 мест, без пропсов) | ≤ 3 000 | тайлы 64×64, ≤ 6 штук | ≤ 6 |
| Персонаж | ≤ 500 | 64×128 | 1 |
| Экран монитора | — (одна плоскость) | 64×64, 4–8 кадров | 1 |

Бюджет треугольников проверяет `tools/validate_assets.py` (A003). Превышение — ошибка, а не предупреждение.

## 5. Текстуры

- **Размеры** — степени двойки: 32, 64, 128. 256 — только для атласа шрифта и по согласованию.
- **Палитра:** CLUT 4 бит (16 цветов) по умолчанию, 8 бит (256) — для плакатов, персонажей и коробок игр.
- **Плотность текселей:** пропсы ~64 пикселя на метр, стены и пол — тайлы ~32 пикселя на метр.
- **Исходник** — PNG в `assets/textures/<id>.png`, в цвете RGB/RGBA. Квантование в CLUT делает конвертер (T011), не рисуйте сразу в индексированном режиме, если это неудобно.
- **Прозрачность** — только 1-битная (вырезанная), без полупрозрачности, кроме специально согласованных эффектов.
- **Текст на текстурах** (плакаты, вывески, коробки) — кириллица, читаемая на 480×272. Мелкий текст — нечитаемым «шумом», крупный — пиксельным шрифтом проекта.

## 6. Модели

- **Только треугольники и четырёхугольники**, без n-гонов. Выгрузка триангулирует сама.
- **Без скрытой геометрии:** нижние грани столов у пола, задние грани у стены — удалить.
- **Плоское затенение** по умолчанию; гладкие нормали — только где это заметно (ЭЛТ-кинескоп, стул).
- **UV:** одна развёртка на объект, без перекрытий, кроме сознательного повтора (тайлы, зеркальные половины).
- **Свет** — запекается в атрибут цвета вершин `Col` (A008). Модель должна выглядеть нормально и без запекания, с одним равномерным цветом.
- **Варианты** (цвет корпуса, грязный/чистый) — сменой палитры CLUT, а не отдельными моделями.

### Персонажи

Собираются **из жёстких частей без скиннинга**, как на PS1:

```
chr_<тип>_root (пустышка на полу)
└── pelvis
    ├── torso
    │   ├── head
    │   ├── upper_arm_l → forearm_l (с кистью)
    │   └── upper_arm_r → forearm_r (с кистью)
    ├── thigh_l → shin_l (со ступнёй)
    └── thigh_r → shin_r (со ступнёй)
```

- Точка отсчёта каждой части — **в её суставе**.
- 11 частей, суммарно ≤ 500 треугольников, одна текстура на персонажа.
- Анимации — ключи на поворотах частей, выгрузка с частотой 15 кадров/с. Список для среза: `idle_sit`, `type`, `lean_back`, `walk`, `sit_down`, `stand_up`, `angry`.

## 7. Именование и файлы

| Префикс | Что | Пример |
|---|---|---|
| `prop_` | Пропсы | `prop_crt17`, `prop_desk_chipboard`, `prop_chair_office` |
| `room_` | Помещения и их части | `room_hall_a`, `room_entrance_stairs` |
| `chr_` | Персонажи и их части | `chr_teen_a`, `chr_teen_a_head` |
| `scr_` | Экраны мониторов | `scr_shooter`, `scr_bsod` |
| `tex_` | Общие текстуры и тайлы | `tex_linoleum`, `tex_wall_paint` |
| `ui_` | Иконки и обои ОС | `ui_icon_cashier`, `ui_wallpaper` |

```
assets/src/<категория>/<id>.blend    исходники Blender (Git LFS)
assets/textures/<id>.png             исходники текстур (Git LFS)
assets/previews/<id>.png             превью 256×256 для ревью (Git LFS)
assets/placeholders/                 процедурные заглушки T013
build/assets/                        выгруженное и сконвертированное — не коммитить
```

- **Один ассет — один `.blend`.** Комната и сцена зала — отдельные файлы, пропсы подключаются в них через Link, а не копированием.
- **Имя объекта в Blender = имя файла** (`prop_crt17` внутри `prop_crt17.blend`).
- Материалы: `mat_<id>` или `mat_<группа палитры>`.

## 8. Как ассет попадает в игру

```
assets/src/*.blend ──(A003: blender -b … --python tools/blender_export.py)──► build/assets/*.obj + цвета вершин
                                                                                   │
                                     (T011: convert_model.py / convert_texture.py) ▼
                                                                          build/assets/*.msh, *.tex
                                                                                   │
                                          (A003: validate_assets.py, render_preview) ▼
                                                    отчёт по бюджетам + assets/previews/<id>.png
```

Одна команда для всего: `python tools/assets.py build` (A003).

---

## 9. Приёмка ассета

1. `validate_assets.py` проходит: бюджеты, имена, трансформации, размеры текстур.
2. Превью `assets/previews/<id>.png` обновлено и закоммичено — по нему ревьюит тот, кто не может открыть Blender.
3. Ассет стоит в сцене рядом с соседями и не выбивается по масштабу и цвету.
4. **Вы** посмотрели превью и одобрили. Раз в веху — проверка в игре на PSP Go.
