# Задачи

Доска задач для вех M0–M6 (вертикальный срез) из [GDD.md §12](../GDD.md#12-вехи). Вехи M7–M10 расписаны крупно — детализируются после среза.

Почему задачи распределены именно так и как их запускать — в [WORKFLOW.md](WORKFLOW.md).

**Исполнители:** `Claude` — Claude Code, `Codex` — ChatGPT Codex, `Человек` — вы (устройство, решения, приёмка).
**Статусы:** `todo` · `in_progress` · `review` · `done` · `blocked`
**«Контракт»** — задача создаёт или меняет интерфейс, на который опираются другие. Её ветку вливать раньше остальных.
